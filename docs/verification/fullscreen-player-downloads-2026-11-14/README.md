# 全屏播放器与下载管理器预览

本轮只改代码和独立远程预览，未推送、合并或发布生产。

## 修改与原因

- 桌面裁切来自导航 CSS 的 `[role="region"][style*="music-player"]`：下载管理器高度公式包含 `--music-player-mobile-reserve`，误命中播放器定位规则，额外偏移 240px。改用明确的 `data-music-player-root`，下载管理器回到视口右侧。
- 下载管理器桌面最大宽度 416px，手机保留两侧 16px；任务标题独立一行，操作另起一行，继续下载与换线路带文字，取消保留二次确认。320px 时操作行自动换行，全部按钮至少 44px 高。
- 播放器入口直接打开全屏 Radix Dialog。桌面左右分区，手机纵向布局，队列独立滚动；关闭、Esc、焦点约束、页面滚动锁定与背景 inert 都已验证。内部菜单提高到全屏之上。封面保持完整显示与 4px 微圆角。

## 浏览器证据

独立预览：远程 `dev-panel-fullscreen-20261114`，本机隧道 `http://localhost:3313`。`layouts.json` 来自 Chromium，覆盖 1440×1000、390×844、320×740。旧版基线桌面面板 x=1344、右边缘1664，超过1440视口；修复后 x=1008、右边缘1424。

`check-layout.mjs` 检查全屏、内部宽度、滚动锁、Esc 焦点恢复和下载面板边界，并保存截图；`check-modal.mjs` 检查嵌套菜单可见、曲库/歌单切换、连续35次Tab焦点约束、背景屏蔽与关闭恢复。后者通过。

脚本在远程专用构建机运行，提供 `ASTRODX_PLAYWRIGHT_PATH`、`ASTRODX_CHROMIUM_PATH`，可用 `ASTRODX_PREVIEW_ORIGIN` 指定预览。布局脚本需提供截图输出目录作为首个参数。资源请求延迟3秒以便暂停下载，未用伪造任务或上传生产数据。预览网络探测状态不等同于生产线路可用性。截图隐藏了 Next 开发工具浮标。

最终工作区远程验证通过：lint、动效 CSS 一致性、共享 UI 与主站类型检查，UI 59 项、主站 772 项测试。追加背景 inert 修复后模态测试再次通过。未触发 GitHub 工作流。
