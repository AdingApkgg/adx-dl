# 主站与 Motion 合并发布验证

本次将 4px 微圆角、完整封面、侧栏导航、播放器队列和本地歌单，与“查找 motion 动画系统规划”会话的动效系统整合。独立预览端口 3312，不覆盖其他会话的工作区。

- 下载浏览器回归 13 项通过，涵盖格式失效确认、触摸尺寸、保存确认、焦点交接和播放器遮挡。
- 播放器浏览器回归 13 项通过，涵盖跨版本队列、增删排序、本地歌单及刷新恢复。音频用有效 WAV 隔离验证。
- 原生转场 9 组通过，涵盖实际导航、固定导航栏、历史记录与减少动态效果策略。
- 回归发现失效下载确认被退出动画保留：改为立即卸载失效确认，保留入口动画；共享动画组件退出时立即设置 inert 和 aria-hidden。未采用试验中的超时或 presence 上下文隔离方案。

JSON 为远程 Chromium 的实际结果。测试中的下载和音频使用隔离数据，不代表每首曲目的外部资源可用性；评论未执行发布操作。生产发布状态以 GitHub Pages 工作流和线上复核为准。
