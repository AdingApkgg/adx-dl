# 谱面上传：ADX、ZIP 与零散素材

日期：2026-10-16（Asia/Shanghai）。本地实现、远程检查和独立复核完成，未推送或部署。

## 使用方式

- 单首 `.adx`、`.zip` 直接选择上传，不必改扩展名；保留原包字节和上传文件名，后端继续校验实际 ZIP 内容。
- 零散素材参考 [MajdataNet](https://majdata.net/) 的分栏选择方式：谱面必选，音乐、曲绘可选；选好后点击「组装并上传」。可选素材能单独移除，也可全部清空。
- 现有文件夹入口保留。所有方式校验完成后仍需主动「保存私有草稿」，不会自动公开。
- 零散素材打包成 `maidata.txt`、`track.*`、`bg.*` 和可选的 `pv.*`；素材字节不改写，排序和时间固定，相同选择可得到相同包以供续传。
- 视频仅随原件保存，不在网页预览；多曲包不作为一首谱面拆分导入。

| 素材 | 格式 | 单文件上限 |
| --- | --- | --- |
| 谱面 | TXT | 1 MiB |
| 音乐 | MP3 / OGG / WAV | 32 MiB |
| 曲绘 | JPG / JPEG / PNG / WebP | 8 MiB |
| 原件视频 | MP4 / WebM | 64 MiB |

素材不能为空；最终包（含 ZIP 头部）最大 64 MiB，个人谱面配额仍为 256 MiB、包含历史版本。沿用有界 Worker、分片、内容哈希、取消和恢复机制，无新增依赖、迁移或上传协议。
