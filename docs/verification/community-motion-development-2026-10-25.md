## 实现范围

- 沿用 web 主站现有 `framer-motion`、共享 MotionProvider、EASE_OUT、springSoft，以及“跟随系统／开启动画／关闭动画”；没有新增依赖。
- 统一页面标题、pathname 切换进入、主导航/移动导航/谱库/社会/账号导航活动背景。进入动画 0.32s、8px、最低透明度 0.92；列表级联间隔 0.035s，最多延后 0.21s；鼠标悬停抬升 2px。
- 覆盖发现/搜索、谱面和谱单、详情相关谱面、收藏、论坛主题/评论、关注动态/通知、创作者工作台/导入、登录/账号设置与后台共享面板。播放器自身沿用现有时间与状态控制。
- 选择条、下载确认面板与浮动队列只添加进入效果；下载任务/历史、工作台/队列数量及实际成功状态复用统一反馈，进度仍由原生 progress 表达真实值。

## 状态与可访问性约束

RouteMotion 不使用 location key、退出快照或 AnimatePresence；query/hash 不触发整页进入，也不因动画重建表单/播放器。原有身份 guard 和账号 key 保留，私密内容随权限变化立即卸载。

SSR/no-JS HTML 始终可读；不会先隐藏内容再等动画。关闭动效时先 complete 再 stop，避免中途残留位移；导航仅替换装饰节点以终止投影动画。hover 使用独立 CSS translate，避免与进入 transform 竞争。列表保留 ul/ol/li 与原 key，数量的可访问文本为真实最终值。
