# 自制谱站整体 UI/UX — 开发记录（待集中验收）

用户取消定向试玩新功能，要求参考Web主站直接整理当前站点。本轮以生产已验收代码后的文档提交4ef062c为基础，新建codex/community-ui-ux，不包含试玩规划或产品实现。

## 已落地的代码

- 紧凑固定页头、清晰的发现/谱面/谱单/论坛主导航；搜索保留入口，更多抽屉承接次级目的地，新增页脚与跳到正文链接。
- 手机端发现/谱面/论坛/我的底部导航，safe-area留白；下载浮条避开底栏，批量栏避开页头。
- 个人空间按谱库/创作/社区/账号分组，桌面侧栏、手机折叠；头像只留核心入口和账号动作。后台按总览/内容/治理/运行分组侧导航，原有12个页面仍可达。
- 首页统一主视觉与搜索、今日谱面和一组最近公开；移除重复搜索/导航/重复列表、账号卡片、过时阶段说明和接口版本。空目录不占大段空间，模块故障保持明确提示。
- 统一宽度、标题、卡片、表单、空态和按钮层级；公开卡片桌面四列，首页不显示批量复选框。谱面预览移至详情主要信息之后，技术UUID/原包说明收进可展开区。
- 论坛/创作工作台/通知/谱库使用统一任务界面；设置和主题正文保持可读行宽。中英日文齐备，共享主题及减少动画设置保留。

未更改业务API、授权、数据模型、版本/发布/下载语义、数字ID或旧链接规则。
