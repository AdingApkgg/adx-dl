# 谱库、公开谱单与下载中心 UI/UX 统一改造

日期：2026-10-21。用户已授权作为一个完整任务实施、集中验证后按正式流程部署；开发期间不运行测试。

## 目标与依据

沿用 web 主站的筛选面板、内容卡片、阶段操作和跨页任务浮层，使发现谱单、私人整理、明确发布与下载保存形成连续流程。保持既有社区数据、权限和下载引擎；不引入新依赖、数据库迁移或统计埋点。细节由实施者按以下规则确定。

参考源码：主站 catalog-browser.tsx、chart-card.tsx、batch-download-bar.tsx、downloads/download-dock.tsx 与 download-history.tsx，以及社区已上线的 community-panel/filter/status/page-heading 规范。不为谱单摘要伪造封面或增加逐卡详情请求。

## 页面与交互

1. 我的谱库与收藏共用带当前态的“我的谱单 / 收藏 / 举报记录”页内导航。新建谱单为主操作，浏览公开谱单为次级入口。私有卡片显示计数、状态和日期；只描述当前页，不冒充全库总数。举报保留处置状态及反馈。收藏保留不可用占位与服务端确认移除。
2. 公开谱单列表使用清楚的搜索面板，URL 回显 q/author；作者筛选收进高级区，保留已有筛选可见性，清空返回 /lists。提交新搜索不携带旧 cursor；加载下一页保留筛选。空结果与未有公开谱单区别说明。卡片名称、简介、作者、首数、发布时间分层，独立作者链接。
3. 公开谱单详情集中标题、编号、作者、首数和发布时间，正文保留公开简介。主要操作为复制，分享为次级，举报单独展开。复制仍完整分页并检查同一 revision，确认可用和不可用数量后执行幂等复制。不可用条目保留顺序与占位；批量选择及下载沿用既有组件。
4. 编辑器分基本信息、谱面整理、保存与发布三个区；桌面主区加操作侧栏，手机按文档顺序。名称/简介 Unicode 计数，容量 200，列表过滤、分页、拖拽与键盘替代操作全部保留。分页夹紧避免删空末页。无效或重复编号给出反馈。保存只更新私有草稿，预览只允许已保存版本；撤回/删除放低强调管理区。未保存保护、revision 冲突、管理员下架限制保持。
5. 下载中心顶部为处理中、等待保存、需要处理的派生数量；处理中仅 queued/running，待保存按 ready 条目，需处理为 paused/failed 或存在失败/换版/不可用项的任务，统计可重叠并用文字说明。队列与最近下载明确分区。每批显示创建时间、状态、字节进度、逐首状态；仅活动任务可暂停，非活动且有未完成条目可继续（包括任务仍为 ready、但保存失败的情况）；全部 ready 才能集合保存。保留单项原包和目录保存后备，取消次级。清空需就地确认，避免误清所有本机记录。
6. 历史使用现有 finishedAt 和编号，明确是保存请求历史，不能声称文件已写入磁盘。限制与集合包解释放帮助折叠区。加入下载保留计划首数/体积确认并可取消。浮层显示简短状态和聚合字节进度，仅活动时可全部暂停，下载页本身不重复浮层。

## 不可变边界与验收

- 三语、深浅色、减少动态效果、键盘焦点、至少 44px 操作目标；320/390/768/1280 无横向溢出或底部遮挡。
- 谱库与收藏仍私有 no-store/noindex、账号隔离。公开详情仍动态鉴权，不混入私人状态。旧数字及 UUID 链接保持兼容。
- 名称 60、简介 500 个 Unicode 字符，每单最多 200、分页 20；下载每批最多 50、缓存 128 MiB、最多 8 待办与 8 历史、24 小时 TTL，身份切换清理、固定版本摘要校验不变。
- ready 为已校验待保存，save_requested 为浏览器保存请求，written 为目录写入完成。刷新后手动继续，不承诺关页后台传输、未完整字节续传或集合包直接作为 ADX 导入。
- 不新增服务端标题/封面请求装饰下载；所有保存继续重新鉴权。撤回/换版阻止旧版本下载。
- 开发阶段只读和修改；进入发布窗口后构建机一次集中类型/lint/单元/DOM/HTTP/真实 Chromium、CI 完整镜像及 512 MiB 恢复验证。修复后重跑受影响检查；最终完整 CI 必须通过。
- 正式部署必须使用现有 coordinator；19 组生产登录态只读无头验收与会话清理通过、RELEASE_COMPLETE 后才标记完成，另核对备份、旧链接、谱面 1 第 6 槽及生产不变量。生产不造测试内容。
