# 自制谱站整体 UI/UX 查漏补缺

本轮延续用户已确认的整体 UI/UX 设计（2026-10-20）及后续内容、谱库、社会、账号/后台和动画设计。用户本次明确要求完整推进，开发阶段不跑测试，发布前集中验证修复后走正式部署；不重新发起视觉选型。实施细节由实现者按现有主站设计体系确定。

## 依据与缺口

参考 web 的 route-loading.tsx、error-view.tsx、not-found-view.tsx、catalog-browser.tsx，以及共享 Skeleton、Sheet、Button 和主题 token。基线为 pre 的683d546b，前次应用944a223b已经完成正式验收；旧结果不能替代本轮验证。

1. 社区站缺少全局站内导航等待反馈与正文焦点衔接；慢请求时仍显示旧页且没有明确状态。新反馈必须保留正文、表单和播放器实例。
2. 错误页只有基础卡片，空态在公开搜索、个人列表和后台存在多套层级；缺少明确恢复去向。空态不能把服务不可用说成没有结果，错误不能展示原始异常/敏感数据。
3. 私有谱面编辑、校对和比较仍是长页中的平铺工具；发布、版本、追加上传和删除层级混杂，校对播放器位置过晚。保留原对象、状态机、key、未保存拦截与选版语义，调整静态结构和视觉优先级。
4. 元数据离开确认和谱面删除使用内联alertdialog，缺少真正的模态焦点管理。补充无文字/路由耦合的共享确认对话框，初始焦点落在取消，取消/关闭不执行写入；等待真实响应时防止重复确认或误关闭。
5. 个人处理中心、举报/讨论记录和帮助/隐私页面仍未完整进入现有阅读、卡片和分组导航体系；超长文本、原始引用号和来源校对信息抢占视觉层级。
6. 手机部分原生表单字号小于16px，长文件名、筛选chip移除含义、空分页导航和来源零行计数仍有可用性缺口；不改虚拟列表几何、解析算法和下载/导入队列。

## 方案取舍

延续现有共享token与社区外壳，增加少量有明确职责的交互/状态原语并迁移遗漏页面，是本轮实施方案。仅按页面补CSS会遗漏键盘、等待/错误和确认行为；整体另建一套外壳则会重复已验收的导航/身份/播放生命周期。原有颜色、字体、动效偏好和核心信息架构继续沿用。

## 设计与约束

- 路由反馈：200ms后显示不伪装百分比的细进度条；只读状态播报；不遮挡操作、不替换旧正文。pathname真正提交且导航空闲后，把焦点交给main-content；初次hydration、search/hash变化、设置/确认等打开中的对话框均不抢焦点，锚点滚动保留。反馈不保存标题、昵称或其他私密页面内容。
- 状态原语：EmptyState(title, description?, actions?)与LoadingState(label)，复用现有Skeleton和token；不可用/错误保留真实分支与重试。服务器/no-JS正文可读，loading不预先隐藏真实内容。
- 确认对话框：共享ConfirmationDialog仅接受调用方文字和onConfirm。使用既有radix-ui依赖的AlertDialog，补焦点陷阱、Esc、取消焦点、关闭还原；pending时不关闭/重复提交，只有原成功响应才能推进原状态机。保留现有确认文案和业务guard。
- 作者流程：统一编辑/校对/比较上下文导航、工作台返回、章节锚点；元数据在主列，发布作为独立任务区，当前预览前置，版本/追加导入/危险操作分区。校对和比较仍消费原分析与受控播放器props，不把播放器放入条件折叠区，不为展示切换创建新key。
- 支持与记录：处理中心/我的举报/我的讨论沿用现有身份guard、草稿boundary和分页；帮助按主题定位并提供对应实际任务入口，隐私只改变阅读层级不改政策内容。所有新文案中/英/日齐全。
- 全局：移动输入16px、主要触控44px、safe-area/scroll-padding、长文本换行、当前导航aria-current、视图按钮aria-pressed、筛选移除有明确动作名称。源代码预览保持每次最多12行及横向滚动，不为了换行改变行高。

## 验证与发布

本轮是一个完整任务。开发时不运行测试、安装、构建、类型检查、预览或浏览器回归；只编写必要回归与静态检查。整批一次新上下文代码复核，重要问题统一修正。准备生产时在指定构建机集中执行共享UI/web与社区检查、全量隔离浏览器和有界备份恢复；再推送/等待CI/合并pre，正式community-deploy.py并验证19组登录态门禁、真实谱面1第6槽、动画/表单/播放器、权限和临时会话清理，通过才complete。生产浏览器只读，不发评论/发布/删除等业务写入。主站回归与主站Pages发布分别记录。

## 五项重点

1. 快速导航、取消导航、同路径筛选与hash、打开设置时后退：反馈不残留，不抢表单/对话框焦点。
2. 身份切换、权限撤回、请求失败：立即移除原私有内容，状态组件与全局播报不保存旧用户信息。
3. pending删除与未保存离开：无重复写入，失败保留确认/草稿，取消不写入，焦点正确回到触发点。
4. 超长中英日标题、文件名和源码：320px无全页溢出，源码仅自身可滚动，12行有界，0行计数正确。
5. 校对版本/难度/左右侧及动画开关变化：原播放时钟、外部seek和实例边界与既有逻辑一致。

## 实施收尾

最终确认组件提供模态内反馈及稳定焦点回退；非上传操作使用通用取消文案。私有编辑身份有效性与设备队列初始化分离；路由完成回调在焦点或原生hash已经改变、或输入控件已聚焦时放弃聚焦正文。集中验证覆盖这些真实失败分支，正式结果见docs/verification/community-ux-completion-2026-10-25.md。
