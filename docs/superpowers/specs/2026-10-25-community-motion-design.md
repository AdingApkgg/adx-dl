# 自制谱站统一动效接入设计

2026-10-25。用户已选择“按推荐完整接入，细节你定”，沿用主站 `framer-motion ^13.4.4` 与 `@astrodx/ui/motion`，不引入另一套动画库。具体参数由实现者确定；开发期间不运行测试，准备上生产时集中验证修复。

## 现状与方案

社区已具备 MotionProvider、首屏偏好脚本、MotionPicker、共享按钮和抽屉。缺口是主要页面和内容/操作状态未统一使用动效。候选是只补基础反馈，或沿用主站完整接入；用户选择后者。主站依赖 Next 内置 React ViewTransition，社区使用 React Router 稳定版，不照搬该运行时。

## 统一实现

- 共享包仅补导出已有 Motion 控制 hook，不改变主站调用方式、不增依赖或安装。
- 社区集中维护 RouteMotion、MotionSurface、MotionGroup、NavigationIndicator、MotionSuccess。缓动沿用 EASE_OUT，交互沿用 springSoft；正文进入约0.28–0.36秒、8px以内，卡片悬浮2px，组内间隔0.035秒且最多延迟0.21秒。
- 页面路径改变时只对当前内容播放进入动画，不按 location.key/search 给 Outlet 加 key，不保留旧页面快照、不等待退出；同页筛选、分页、数据刷新不重新播放整页动画。
- SSR与无JS始终可读：所有内容表面的 initial=false，进场在客户端观察/导航后触发，最低透明度0.9。不把正文藏在 opacity:0 里等待 observer。
- 保留原生 main/article/section/ul/li、锚点、标签、ARIA和键盘操作；非交互容器不加 whileTap，不额外变成焦点。
- 表面在首个可视时进入一次，列表使用保持原标签/React key的组内级联，不对大网格做 layout 测量。身份/权限变化后内容立即移除，不使用 AnimatePresence 延后私密内容卸载。
- 顶栏和移动导航活动背景使用有界的共享布局反馈；页头、侧栏、选择条与下载浮层位于页面转场外。下载/批量选择出现时轻量进入，移除立即完成；成功图形只对应真实成功状态，数字显示保持可访问的最终值。
- 覆盖发现/搜索、谱面与谱单、详情与评论、论坛、用户/动态/通知、工作台/导入/下载、登录/设置/后台。通过共享卡片/标题/面板覆盖复用页面，保留所有业务逻辑和数据接口。
- 跟随系统/开启动画/关闭动画与主站完全共用偏好；关闭或系统减少动画时立即中止位移、级联、数字和图形动画，恢复静态终态。不得影响谱面播放本身。

## 验收安排

开发阶段只读改代码与静态复核。集中阶段远程验证共享包与社区类型、DOM/SSR、现有业务与真实浏览器；检查SSR可见、输入/播放器/导入不重建、关闭动画立即生效、账号切换无旧内容、键盘焦点与320/390/768/1280布局。正式19组门禁继续保留，增加同组中的动画偏好/状态保持观察，不拿视觉截图替代业务与权限检查。当前仅授权开发，不推送或部署本轮新功能。
